API reference¶

Every public method is available on stockdex.Ticker. The classes below are the mixins it is built from, one per data source.

from stockdex import Ticker

stock = Ticker(ticker="AAPL")
etf = Ticker(isin="IE00B4L5Y983", security_type="etf")
